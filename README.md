# WildLife SA Rescue Operations System

## Description

The WildLife SA Rescue Operations System is a Java-based console application developed to assist a non-profit wildlife conservation organisation with managing wildlife rescue cases across Southern Africa.

The system allows conservation staff to create and manage rescue cases for injured, orphaned and endangered animals. Users can search for rescue cases using a unique Rescue Case ID, update rescue statuses, monitor rescue operations and generate rescue reports.

The application uses object-oriented programming principles including inheritance, abstraction, encapsulation, interfaces, method overriding and polymorphism. Rescue cases are stored in an ArrayList while the application is running.

## Main Features

- Create new wildlife rescue cases.
- Manage injured, orphaned and endangered animal rescues.
- Search for rescue cases using a Rescue Case ID.
- Update rescue statuses.
- Start and complete rescue operations.
- Calculate rescue costs according to rescue type.
- Determine rescue priority.
- Display all stored rescue cases.
- Generate individual rescue summaries.
- Generate a complete wildlife rescue report.
- Validate user input and prevent duplicate Rescue Case IDs.
- JUnit testing for core application functionality.
